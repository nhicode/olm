🔎 Web Extractor

Nhập URL → lấy HTML + tất cả đường dẫn JS / CSS / Image / Font / Anchor
⚠️ Trình duyệt chặn CORS khi fetch trực tiếp → cần proxy công khai. Nếu proxy lỗi, chuyển sang tab Paste HTML, hoặc dùng nút Copy DevTools Script để chạy trực tiếp trên trang gốc (đầy đủ nhất).
💡 Chế độ static-parse không có: Shadow DOM, nội dung iframe, localStorage/cookies, computed CSS variables, kích thước ảnh thật. Để lấy đầy đủ → dùng nút 🧪 Copy DevTools Script rồi paste vào Console của trang gốc.
